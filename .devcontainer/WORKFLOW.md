# Devcontainer Configuration Refactor

## File Structure (DRY approach)

```
.devcontainer/
├── devcontainer-build.json        ← Local-build template (full schema-valid config)
├── devcontainer-prebuilt.json     ← Pre-built template (full schema-valid config)
├── devcontainer.json              ← Active config (copied from one template)
├── devcontainer.local.json        ← Optional local-mount variant (full schema-valid config)
├── Dockerfile                     ← Base image + tools
├── devcontainer-workflow.sh       ← Mode switching automation
└── features/workshop-tools/       ← Custom feature (separate, required by spec)
```

## Configuration Mode

### Active Build Mode
- `devcontainer-build.json` contains the full local-build config
- `devcontainer-workflow.sh use-local` copies it to `devcontainer.json`

### Pre-built Mode (Template)
- `devcontainer-prebuilt.json` contains the full image-based config
- `devcontainer-workflow.sh use-prebuilt` copies it to `devcontainer.json`

### Local Developer Overrides (Optional)
- `devcontainer.local.json` contains a full schema-valid config with extra mounts
- Keep machine-specific values in `.env.local`

## Usage

### Initial Setup (Build Locally)
```bash
# devcontainer.json already points to build mode
cd .devcontainer
# In VS Code: Cmd+Shift+P > Dev Containers: Rebuild Container
```

### Build and Push to GHCR
```bash
docker login ghcr.io
./devcontainer-workflow.sh build-and-push latest
```

### Switch to Pre-built Mode
```bash
./devcontainer-workflow.sh use-prebuilt
# In VS Code: Cmd+Shift+P > Dev Containers: Rebuild Container
```

### Add Local Developer Overrides
Update `.devcontainer/devcontainer.local.json`:
```json
{
  "image": "ghcr.io/ralphke/agentic-coding-image:latest",
  "mounts": [
    "source=${localEnv:MY_LOCAL_DATA},target=/workspace-data,type=bind"
  ]
}
```
Then set `.devcontainer/devcontainer.local.json` as your active devcontainer config in VS Code.

## Key Points

- **Build template** (`devcontainer-build.json`): Safe to commit, local Dockerfile mode
- **Pre-built template** (`devcontainer-prebuilt.json`): Safe to commit, GHCR image mode
- **Active config** (`devcontainer.json`): Generated by copy from one template
- **Local config** (`devcontainer.local.json`): Optional full config with mounts
- **Workflow script** (`devcontainer-workflow.sh`): Automates mode switching by copy

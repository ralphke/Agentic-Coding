# Lab 01: Tests and Refactor Loop (Intermediate)

## Prerequisites

- **Primary IDE:** [VS Code Agents application](https://code.visualstudio.com/docs/copilot/agents-app) (see doc/setup.md for setup)
- GitHub account with an active Copilot subscription
- Completed lab/01-beginner/01-copilot-foundations.md

## Goal

Use Copilot to drive a red-green-refactor cycle with explicit test-first prompts.

## Exercises

1. Start from a small function with known edge cases.
2. Prompt Copilot to write failing tests first.
3. Prompt Copilot to implement the minimum passing change.
4. Prompt Copilot to refactor for readability without changing behavior.
5. Request a review checklist and run through each item.

## Success criteria

- Tests fail before implementation and pass afterward.
- Refactor does not change behavior.
- You can trace every code change to a requirement or test.
